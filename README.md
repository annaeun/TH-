# 외국어 리스닝 학습 노트

유튜브 영상이나 영상/음성/이미지/PDF 파일을 넣으면, Gemini AI가 스크립트를 받아적고
한국어로 번역하고 핵심 단어까지 정리해주는 개인용 언어 학습 웹앱입니다.
태국어 · 스페인어 · 영어를 지원합니다.

## 주요 기능

- **언어 선택**: 상단에서 태국어 / 스페인어 / 영어 중 선택. 마지막에 고른 언어가
  다른 언어로 바꾸기 전까지 그대로 유지됩니다.
- **다양한 입력 방식**: 유튜브 링크 또는 파일 업로드(끌어다 놓기 지원)
- **분석 결과**: 번호가 매겨진 원어 스크립트 + 한국어 번역 + 단어 정리표를 한 화면에서 확인
- **단어표 직접 편집**: 스크립트를 보다가 빠진 단어가 있으면 원어 단어만 입력하고
  추가하면, 한국어 뜻과 설명을 AI가 자동으로 채워줍니다. 잘못 추출된 단어는 표에서
  바로 삭제 가능합니다.
- **단어 발음 듣기 + 발음기호**: 단어표 각 행의 🔊 버튼을 누르면 발음을 들을 수
  있습니다. 방금 분석한 영상/음성이 화면에 남아있으면 그 원본에서 해당 단어가
  나오는 부분을 그대로 재생하고(진짜 원어민 발음), 그게 불가능한 경우(사진/PDF
  분석, 원본을 다시 첨부하지 않은 히스토리 기록 등)에는 브라우저 음성으로 대신
  들려줍니다. 발음기호 열에는 태국어는 음절 표기(예: พัด-ทะ-ยา), 스페인어/영어는
  국제음성기호(IPA)가 표시됩니다.
- **분석 히스토리**: 로그인한 사용자의 분석 결과는 자동으로 저장되어, 화면 상단
  "히스토리" 버튼에서 예전 결과를 다시 불러올 수 있습니다. 6개월이 지난 기록은
  자동으로 삭제됩니다. (파일 업로드로 분석한 기록은 원본을 다시 첨부해야 영상
  미리보기가 나타나고, 유튜브 링크 기록은 그대로 다시 재생됩니다.)
- **복사하기**: 스크립트/번역/단어표를 각각, 또는 한 번에 전체 복사할 수 있습니다.
  단어표는 서식이 있는 형태로도 복사되어 네이버 블로그 등에 붙여넣어도 표 모양이
  유지됩니다.
- **넓은 화면 2단 레이아웃**: 화면이 충분히 넓으면 입력 영역과 결과 영역이 좌우로
  나란히 배치됩니다.
- **로그인/키 보안**: 실제 배포된 사이트는 구글 로그인을 해야 사용할 수 있고
  (계정 제한 없음), Gemini API 키는 코드에 들어있지 않고 각자 브라우저에만
  저장됩니다 (로컬에서 미리보기할 때는 로그인 없이 바로 테스트할 수 있습니다).

## 사용법

1. **(배포된 사이트인 경우)** 구글 계정으로 로그인합니다.
2. 오른쪽 위 톱니바퀴(⚙️) 아이콘을 눌러 Gemini API 키를 입력하고 저장합니다.
   키가 없다면 팝업의 "키 발급받기" 링크(https://aistudio.google.com/app/apikey)로
   무료 발급받을 수 있습니다. "연결 테스트"로 키가 정상인지 바로 확인할 수 있습니다.
3. 상단 **"분석할 언어"**에서 학습할 언어(태국어/스페인어/영어)를 선택합니다.
4. 아래 두 가지 중 하나로 자료를 넣습니다.
   - 유튜브 영상 링크 입력 (공개 영상만 가능)
   - 영상·음성·이미지·PDF 파일 업로드 또는 화면에 끌어다 놓기
5. **"분석 시작"**을 누르면 잠시 후 스크립트 → 한국어 번역 → 단어 정리표 순서로
   결과가 나타납니다.
6. 단어표에 없는데 필요한 단어가 있다면, 표 아래 "단어 직접 추가하기"에 원어 단어만
   입력하고 버튼을 누르면 한국어 뜻/설명이 자동으로 채워져 표에 추가됩니다. 필요 없는
   단어는 각 행의 ✕ 버튼으로 지울 수 있습니다.
7. 단어표 각 행의 🔊 버튼으로 발음을 들을 수 있습니다.
8. 각 영역의 "복사하기" 또는 맨 아래 "전체 복사하기"로 원하는 곳에 붙여넣습니다.
9. 화면 상단 "히스토리" 버튼으로 예전 분석 결과를 언제든 다시 불러올 수 있습니다
   (로그인한 경우에만 저장/조회됩니다).

## 지원 파일 형식

| 종류 | 형식 | 처리 방식 |
| --- | --- | --- |
| 영상 | MP4·MOV·WEBM·AVI·WMV·FLV·3GP | 음성을 처음부터 끝까지 받아적어 분석 |
| 음성 | MP3·WAV·AAC·OGG·FLAC·AIFF | 음성을 처음부터 끝까지 받아적어 분석 |
| 이미지 | JPG·PNG·WEBP·HEIC 등 | 사진 속 텍스트를 읽어 분석 (표지판, 메뉴판, 자막 캡처 등) |
| 문서 | PDF | 문서 안의 텍스트를 읽어 분석 |

유튜브 링크는 **공개(public) 영상만** 지원됩니다. 틱톡·인스타그램 등 다른 사이트
링크는 지원되지 않으니, 해당 영상은 다운로드한 뒤 파일 업로드를 이용해주세요.

## 로컬에서 미리보기

```bash
npx serve .
```

`localhost`로 접속하면 로그인 없이 바로 기능을 테스트할 수 있습니다. (실제 배포
도메인에서는 로그인이 필요합니다.)

## 배포 및 운영 설정

Firebase 프로젝트 연동, Gemini API 키 보호, 히스토리 자동 삭제(TTL) 설정,
실제 배포 명령어 등 운영에 필요한 내용은 [SETUP.md](./SETUP.md)를 참고하세요.

## 기술 스택

- **Firebase Hosting** — 정적 페이지 배포
- **Firebase Authentication (Google 로그인)** — 사용자 인증 (가입 제한 없음)
- **Firestore** — 분석 히스토리 저장(6개월 자동 삭제)
- **Google Gemini API** — 영상/음성/이미지/문서 분석. 특정 모델이 혼잡하면
  `gemini-3.5-flash-lite → gemini-flash-latest → gemini-3.6-flash` 순서로
  자동 전환합니다.

이 저장소의 코드에는 어떤 비밀 키도 포함되어 있지 않습니다 (Firebase 설정값은
공개되어도 안전한 값이고, Gemini API 키는 각자 브라우저에만 저장됩니다) — 그대로
공개 저장소에 올려도 괜찮습니다.
